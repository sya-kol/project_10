# Проект 10_1 банковские операции

## Описание:
Проект 10_1 банковские операции - предоставляет функции для фильтрации 
и сортировки данных о банковских операциях

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/sya-kol/project_10.git
```
2. Перейдите в папку проекта:
```
cd project_10
```
3. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

Функция get_mask_card_number принимает номер карты в виде числа и возвращает маску номера XXXX XX** **** XXXX

print(get_mask_card_number(7000792289606361))

>>'7000 79** **** 6361'


Функция get_mask_account принимает номер счета в виде числа и возвращает маску номера **XXXX

print(get_mask_account(73654108430135874305))

>>'**4305'

Функция get_mask_account_card  умеет обрабатывать информацию о картах и о счетах, 
принимать один аргумент — строку, содержащую тип и номер карты или счета, 
возвращает строку с замаскированным номером.

info_numbers = [
                ('Maestro 1596837868705199'),
                ('Счет 35383033474447895560),
                ('Visa Classic 6831982476737658'),
                ('Счет 73654108430135874305'),
                ('Visa Gold 5999414228426353')]

print(get_mask_account_card(info_numbers))

>>[('Maestro 1596 83** **** 5199'),
    ('Счет **5560'),
    ('Visa Classic 6831 98** **** 7658'),
    ('Счет **4305'),
    ('Visa Gold 5999 41** **** 6353')]

Функция get_date принимает на вход строку с датой в формате
"2024-03-11T02:26:18.671407" возвращает строку с датой в формате "ДД.ММ.ГГГГ

print(get_date('2024-03-11T02:26:18.671407'))

>>'11.03.2024'

Функция get_filter_by_state принимает список словарей и опционально значение для ключа 
state (по умолчанию 'EXECUTED'). 
Функция возвращает новый список словарей, содержащий только те словари, у которых ключ 
state соответствует указанному значению.

banking_operation = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
    ]

print(get_filter_by_state(banking_operation))

>> [
{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}
]

Функция get_sort_by_date, которая принимает список словарей и необязательный параметр, 
задающий порядок сортировки (по умолчанию — убывание). 
Функция должна возвращать новый список, отсортированный по дате.

print(get_sort_by_date(banking_operation))

>>[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
  {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, 
  {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
  {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
