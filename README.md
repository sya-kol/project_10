# Проект 10 банковские операции

## Описание:
Проект 10_1 банковские операции - предоставляет функции для фильтрации 
и сортировки данных о банковских операциях.

Проект 10_2 тестирование функций фильтрации и сортировки данных 
о банковских операциях.

Проект 10_3 создание модуля generators, который содержит 
функции для работы с массивами транзакций.

Проект 10_4 разработан декоратор log, который автоматически 
регистрирует детали выполнения функций, такие как время вызова, 
имя функции, передаваемые аргументы, 
результат выполнения и информация об ошибках.

Проект 10_5 разработана функция, которая принимает на вход 
путь до JSON-файла и возвращает список словарей с данными 
о финансовых транзакциях. Так же разработана функция, 
которая принимает на вход транзакцию и 
возвращает сумму транзакции в рублях, тип данных — float

Проект 10_7 реализовано считывание финансовых операций из CSV- и XLSX-файлов

Функция get_file_operation 
принимает на вход путь до JSON-файла и возвращает 
список словарей с данными о финансовых транзакциях.
Если файл пустой, содержит не список или не найден, 
функция возвращает пустой список. 

Функция get_exchange
принимает на вход транзакцию и возвращает сумму 
транзакции (amount) в рублях, тип данных — float. 
Если транзакция была в USD или EUR, происходит обращение 
к внешнему API для получения текущего курса валют и 
конвертации суммы операции в рубли.

Функция func_read_csv принимает на вход csv-файл,
читает и выдает список словарей с транзакциями.

Функция func_read_excel принимает на вход excel-файл,
выдает список словарей с транзакциями.
